# Ahmad Karim

**Applying AI and machine learning to data problems, with Python development and web applications.**

My core technical focus is **artificial intelligence, machine learning and data analysis**. I work with Python, pandas, NumPy and scikit-learn to prepare datasets, explore patterns, build classification and regression pipelines, and evaluate predictions against simple baselines.

My projects cover random-forest classification and regression, support-vector classification, TF-IDF retrieval, and exploratory computer-vision work with Keras CNNs and YOLOv5. Their READMEs explain the implemented methods, verification results and remaining limitations. Python and Django web development complement this work through applications such as SecondServe.

## Technical focus

- **Data analysis and machine learning:** Python, pandas, NumPy, scikit-learn, preprocessing and evaluation.
- **Application development:** Django, SQL, SQLite, PostgreSQL, HTML, CSS and JavaScript.
- **Software foundations:** validation, relational data and automated testing.

The repository READMEs distinguish original coursework, current implementations and AI-assisted maintenance. The [chatbot](https://github.com/meahmadkarim/Topical_Chatbot), [facial-expression](https://github.com/meahmadkarim/facial-expression-classification) and [road-turn detection](https://github.com/meahmadkarim/road-turn-detection-yolov5) experiments document their remaining data or training limitations.
